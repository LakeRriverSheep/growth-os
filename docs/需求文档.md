# I · 需求文档 v1.0（已确认）

> 状态：江洋已于 2026-09-01 确认。产品名：**I**——"电子版的自己"。
> 本文档是软件工程的第一步：先想清楚做什么、不做什么。

## 1. 一句话定义

一个 AI 辅助的个人成长软件：记录我的目标与状态，通过问答式引导生成具体行动计划，每天记录执行情况——它是"我的电子存在"，名字叫 **I**。

## 2. 目标用户

第一版只有一个人：我自己（江洋）。
先自用 → 用满 1 个月后再考虑给别人用。

## 3. MVP 功能清单（第一版只做这 3 个）

### F1 目标卡片
- 首页是一排目标卡片（可增删改）
- 我的初始 5 个目标：

| 目标 | 具体描述 | 截止 |
|---|---|---|
| 健身 | 练出薄肌（提升骨骼肌，当前 23.9kg） | 长期 |
| 雅思 | 口语 8.0（27 年考试） | 2027 |
| 音乐 | 电子琴入门（后续加吉他） | 长期 |
| 软件 | 精通软件工程，做出这个产品本身 | 长期 |
| 赚钱 | 独立产品产生第一笔收入 | 待定 |

### F2 AI 问答式计划生成
- 点击某个目标卡片 → 进入问答流程（3~5 步选择题）
- 例如健身：问训练频率（4天/周）、场地（健身房）、目标（薄肌）→ 生成每周训练计划 + 饮食热量建议
- 生成的计划保存，可重新生成

### F3 每日记录
- 每天一条记录，绑定日期：训练内容（项目/组数）、饮食与热量、完成情况
- 目标卡片上能看到进度

## 4. 明确砍掉的（第二期再说，谁提都不加）

- 日记 / 心情 / 想法记录
- 简历式完整个人档案
- "效率建议"智能分析
- 手机 App（先做网页，手机浏览器能用就行）
- 多用户 / 注册登录（第一版单用户，不做账号系统）
- **社交功能（2026-09-01 新增，二期重点）**：基于"电子自我"数据匹配相似的人——交同类朋友、聊天、分享交流。因记录了用户超全面的个人信息，匹配与交流极其高效。依赖多用户体系，必须在"先自用跑通"之后做。

## 4.1 第二期设计储备（来自竞品 LifePlanner 调研，2026-09-01）

- 习惯→目标关联：每次打卡自动推进对应目标进度（如练琴 30 分钟 = 「音乐」目标 +1%）
- AI 输出动作卡：AI 生成的计划直接一键变成可点卡片，不是一段死文字
- 离线优先：数据先存本地，云同步可选（第一版不上云，省部署成本）

## 5. 页面结构（第一版共 3 个页面）

1. **首页**：目标卡片列表
2. **目标详情页**：问答生成计划 + 展示当前计划
3. **记录页**：按日期写当日记录

## 6. 技术栈

- 数据库：SQLite（先本地存，够用）
- AI：国内大模型 API（DeepSeek / 通义 / Kimi 选一个）
- 部署：先本地跑，第 4 周再上线

## 9. v2.0 方向（2026-09-02 江洋新构思，自己设计不抄竞品）

- **手机号注册登录**（第一页）→ 暂缓
- **深浅色主题跟随手机系统**（白/黑）→ 暂缓
- **首屏核心交互：上下滑动选择目标**——选用户当前最想实现的第一个目标
- **目标库覆盖一生**：如英语考试，点进去再细分四六级/雅思/小学初中高中英语等
- **先只深度做「健身」**：
  - 首屏滑到健身，UI 要简洁大（暂定大长方形卡片）
  - 点进去：更详细的目标多选（减脂/增肌等）、有器械/无器械/健身房/在家（可多选）
  - 获取用户位置 → 选择他去的健身房 → 选择想用的器械
  - 收集目标+个人信息 → **直接给超级详细的计划：应该吃多少、练多少**

## 10. v2.1 饮食模块改版（2026-09-11 已实现）

**背景**：v2.0 是「每天固定的详细菜单 + 逐条打勾」，实际用起来每天都要维护、难坚持，而且不同天的食材重复度低、记不牢。

**改版口径**：

- **不再排每天菜单**。改成「从自己的食材库里按宏量营养素拼餐」：每一餐 = 蛋白质 1 份 + 碳水 1 份 + 蔬菜管饱 + 脂肪按需。
- 早 / 中 / 晚 三餐各给：**目标宏量**（热量 / 蛋白 / 碳水 / 脂肪）、四个分组的**可选项清单**（每项带自己的 P/C/F/热量）、一个**推荐组合**与合计、一条针对性提示。
- 食材库全部来自真实库存（冰箱采购清单），新买的**虾仁 / 彩椒 / 西兰花**标为「新」。食材库在完整计划页可展开查看。
- 三餐日节点直接渲染搭配卡，只留一个「这一餐按搭配吃完了」的勾选；原来的「✎ 改清单」（diet_overrides）整套移除。

**宏量口径（对齐已定方案）**：

| 项 | 口径 | 55kg 本人值 |
|---|---|---|
| 蛋白质 | 2.0 g/kg | 110 g |
| 碳水 | 余量算但封顶 4 g/kg（训练日） | 训练日 220 g / 休息日 165 g |
| 脂肪 | 0.8 g/kg 且不低于 45 g | 45 g |

三餐配比：蛋白 30/40/30、碳水 25/42/33、脂肪 30/40/30。
推荐组合全天合计 ≈1746 kcal · 蛋白 116 g / 碳水 215 g / 脂肪 49 g（对比目标 1944 kcal，差额即减脂缺口）。

**落地位置**：`src/lib/diet.ts`（食材库 + 搭配引擎）、`src/lib/fitness.ts`（nutrition 口径）、`src/app/goal/fitness/_components/MealPairCard.tsx`（搭配卡 / 全天合计 / 食材库）、`tests/diet.test.ts`（7 条单测）。
